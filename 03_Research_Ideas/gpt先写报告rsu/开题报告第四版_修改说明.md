## 三 技术保留与弱化

- 保留车辆运动、转弯、三维几何遮挡、多站距离/角度/径向速度观测、CKF候选、未来SINR分布、CP、FIM、VoI和资源优化。
- 明确EKF一阶线性化、UKF sigma点和CKF容积积分的差异；三者公平比较，不预设CKF优于UKF。
- VB降为噪声参数自适应增强；分布式VB仅在能定义局部后验、交换消息和共享信息扣除规则时探索，不列毕业前提。
- BCRB只在模型一致的简化条件下作理论参照；删除将复杂跳变模式下界作为必须完成主线的安排，不将下界当滤波算法。
- NLoS保留为传播条件和观测可用性因素，不再以复杂多径或非视距信号恢复作为研究内容一创新。
- MAPPO保留为传统方案验证后的候选调度算法；规则/贪心及小规模传统优化是主线。ST-GNN仅作可选预测特征或残差模型，不与MAPPO并列成可互换调度器。
- 新增动态货车时刻A/B案例，图中被货车阻断的目标路径不当作有效观测；被挡站仍可观测货车，由其他站观测目标。直路为基础、SUMO转弯交叉口为扩展。

## 四 公式及物理模型调整

第三版15式重组为第四版26个连续编号原生数学公式。不是逐式机械沿用，主要映射如下。

| 第四版式号 | 内容与修订 |
| --- | --- |
| 2-1—2-2 | 联合状态与协调转弯；给出状态维度、分量单位及零转率连续极限 |
| 2-3—2-4 | 联合轨迹几何遮挡概率、逐步模式概率递推；随机条件下标近似，避免几何和马尔可夫两次计入同一遮挡 |
| 2-5—2-7 | 有效测量、资源相关噪声及块相关协方差；完全遮挡删除测量，不伪装成普通高斯噪声 |
| 2-8—2-9 | CKF容积点和模式混合矩；保留多峰样本，未知相关性不直接相乘共享先验后验 |
| 2-10—2-12 | 单PRB SINR、跨站同频干扰、联合场景积分；干扰增益取发射波束到受扰车辆的增益 |
| 2-13—2-14 | 含候选站/动作/PRB/预测时点的块最大分数、有限样本分位数；样本不足时不输出虚假有限下界 |
| 2-15 | 局部FIM和预测协方差近似；固定工作点、有效测量集合，不能当全局精确BCRB |
| 2-16 | 核心VoI重写：无新增信息的最优期望损失，减去对未来观测积分后的重优化期望损失；相同动作域隔离信息价值 |
| 2-17—2-19 | 按通信实际时长计算有效速率、两阶段联合目标及CVaR辅助变量表达；避免重复扣通信时间 |
| 2-20—2-22 | 唯一关联、站容量、PRB/功率绑定、独立感知任务及资源激活 |
| 2-23—2-26 | 全局时分时间、分阶段带宽、每站峰值/帧能量及模型可靠性；报告不可行与采样误差 |

采用“全网同步感知前缀内TDMA任务 + 通信阶段站间频率复用”的一致架构。不同时间复用带宽，不再错误叠加感知带宽和通信带宽；通信同频干扰保留。货车独立测量需计入同一任务和时间预算，不能当免费旁信息。

因果时序改为：已有信息规划感知 → 实际获取测量 → 更新后验 → 确定慢层主关联与切换 → 快层PRB/功率 → 下一帧。事前虚拟观测只用于期望价值计算，不可当实际信息提前使用。

28 GHz、15 m/s时最大多普勒约1400 Hz、常用相干时间估算约0.30 ms。因此100 ms/1 ms被明确为调度粒度；小尺度衰落按统计风险及更细仿真采样处理，不能声称1 ms内瞬时CSI不变。

## 七 待导师确认及后续验证

1. 是否接受“全网感知前缀内串行任务”作为基础ISAC架构，以及其在较多车辆下的开销；若改为并行感知，需要新增互扰/正交资源模型而非只改图。
2. 式2-6资源—噪声尺度关系、噪声地板及有效积累时长需用回波模型拟合，不是已推导精确CRB；测量偏置和低SNR区间需验证。
3. 基础采用测量级集中融合，未知相关性使用保守性检验；若改分布式VB，必须明确局部后验和重复信息处理，不能直接相乘。
4. BCRB是否值得作为简化模型附加分析；未能给出一致推导时不强制保留复杂理论界。
5. CP同时覆盖需要预定义有限动作目录、完整候选标签及交换校准单位；连续功率动作、负载变化、轨迹漂移和缺反事实标签时，不外推原覆盖保证。
6. 纯信息VoI与含硬可靠性约束的端到端调度目标应分别核验；有信息不等于真实中断逐次下降，更不等于扣除感知时间后净收益必为正。
7. VoI嵌套采样和内层优化的开销、快层时限、可行回退和不可行服务记录需要实现后测量；MAPPO仅在主线和计算预算允许时开展。
8. 100ms慢帧、1ms快粒度、20ms感知上限、5—15辆基础规模和0.05/0.10风险水平为拟定研究配置，不是已满足的业务标准；实际毕业时间和题目审批以导师、学院为准。
