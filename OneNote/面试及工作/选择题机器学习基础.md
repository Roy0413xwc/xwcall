**二、迁移学习的基本流程**

一般有三步：

**1. 预训练**

先在一个大规模数据集上训练模型。

例如：

- 图像模型在 ImageNet 上训练
- 语言模型在大规模文本语料上训练
- 大模型在海量互联网文本上预训练

这个阶段模型学到的是**通用特征**。

**2. 迁移**

把预训练好的模型拿到新任务上。

例如：

原来模型会识别很多通用图像特征，现在拿来识别医学 X 光片。

**3. 微调**

在新任务的数据上继续训练。

常见方式有两种：

| **方式** | **含义** |
| --- | --- |
| 冻结前面层 | 前面层参数不动，只训练最后几层 |
| 全量微调 | 所有参数都继续训练 |

**四种学习方式快速总结**

| **类型** | **有没有标签** | **核心目标** | **常见任务** |
| --- | --- | --- | --- |
| 监督学习 | 有标签 | 学输入到输出的映射 | 分类、回归 |
| 无监督学习 | 无标签 | 发现数据内部结构 | 聚类、降维 |
| 半监督学习 | 少量有标签 + 大量无标签 | 降低标注成本，提高效果 | 小样本分类 |
| 强化学习 | 没有固定标签，有奖励信号 | 学习最优动作策略 | 游戏、机器人控制 |

| **选项** | **算法** | **是否无监督学习** | **原因** |
| --- | --- | --- | --- |
| A | 随机森林 | 不是 | 需要标签，常用于分类/回归 |
| B | PCA | 是 | 不需要标签，用于降维 |
| C | GMM | 是 | 不需要标签，用于聚类/分布建模 |
| D | K-Means | 是 | 不需要标签，用于聚类 |

很多题会这么问：

SVM 如何处理非线性可分问题？

答案一般是：

使用核函数，将数据隐式映射到高维特征空间，使其线性可分。

注意关键词：

非线性可分

高维空间

隐式映射

内积

核技巧

看到这些，基本就是在考 SVM 核函数。

| **场景** | **常用核函数** |
| --- | --- |
| 数据线性可分 | 线性核 |
| 非线性关系明显 | RBF 核 |
| 存在多项式关系 | 多项式核 |
| 不确定用什么 | RBF 核常作为默认选择 |
