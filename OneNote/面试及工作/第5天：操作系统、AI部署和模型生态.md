**下午：AI 与操作系统结合**

这是你可以形成差异化优势的部分。

**1. 推理资源**

理解：

\[

\text{模型显存}

\approx

\text{参数数量}

\times

\text{每个参数字节数}

\]

例如 FP16 每个参数约 2 字节，仅权重部分：

\[

7\times10^9\times2

\approx14\text{ GB}

\]

实际运行还包括：

- KV Cache；
- 激活值；
- CUDA Context；
- 临时缓冲区。

**2. KV Cache**

自回归生成时缓存历史 Token 的 Key 和 Value，避免每生成一个 Token 都重新计算全部历史内容。

需要理解：

- 上下文越长，KV Cache 占用越大；
- Batch 越大，占用越大；
- KV Cache 影响并发能力。

**3. 量化**

了解：

- FP32；
- FP16/BF16；
- INT8；
- INT4。

量化的作用：

- 降低显存；
- 提升部署效率；
- 可能造成精度损失。

**4. 推理性能指标**

必须认识：

- TTFT：首 Token 延迟；
- TPOT：每个输出 Token 的时间；
- Throughput：吞吐量；
- QPS：每秒请求数；
- 并发数；
- Token/s；
- 显存占用。

**5. 系统优化概念**

了解即可：

- Continuous Batching；
- Prefix Cache；
- Tensor Parallel；
- Pipeline Parallel；
- Data Parallel；
- CPU Offload；
- 异步 I/O；
- 请求调度。
