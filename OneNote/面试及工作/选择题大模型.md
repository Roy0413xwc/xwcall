LoRA 不直接训练原来的大矩阵，而是在原矩阵旁边加两个低秩矩阵：

$W$$∈$$﷐$$R$$﷮$$d$$×$$d$$﷯$

如果 LoRA rank 为 $r$，那么新增参数量是：

$d$$×$$r$$+$$r$$×$$d$$=2$$d$$r$

本题中：

- hidden size = 4096
- LoRA rank = 64
- 每层只对 attention 的 **query 矩阵和 value 矩阵** 加 LoRA
- LLaMA 7B 有 32 层

| **方法** | **核心思想** | **是否需要奖励模型** | **是否常用 PPO** |
| --- | --- | --- | --- |
| RLHF | 用人类偏好训练奖励模型，再用强化学习优化模型 | 需要 | 常用 |
| DPO | 直接用 chosen/rejected 偏好对训练模型 | 不显式需要 | 不需要 |
| RLAIF | 用 AI 模型代替人类产生反馈或偏好数据 | 可以需要，也可以结合其他方法 | 视具体方法而定 |
