**记笔记版**

SARSA 和 Q-Learning 都是基于 TD Target 更新动作价值函数 $Q$$﷐$$s$$﷮$$a$$﷯$ 的方法。SARSA 使用实际按照当前策略选出的下一动作 $﷐$$a$$﷮$$′$$﷯$ 构造目标：

$r$$+$$γ$$Q$$﷐$$﷐$$s$$﷮$$′$$﷯$$﷮$$﷐$$a$$﷮$$′$$﷯$$﷯$

因此它学习的是当前策略的价值，是 on-policy 方法。Q-Learning 不使用实际下一动作，而是假设下一状态会选择价值最大的动作：

$r$$+$$γ$$﷐$$﷐$$max$$﷮$$﷯$$﷮$$﷐$$a﷮$$′$$﷯$$﷯$$Q$$﷐$$﷐$$s$$﷮$$′$$﷯$$﷮$$﷐$$a$$﷮$$′$$﷯$$﷯$

因此它直接学习最优动作价值函数 $﷐$$Q$$﷮$$∗$$﷯$，属于 off-policy 方法。表格方法直接更新 Q 表，而 DQN 使用神经网络近似 Q 函数，并通过最小化 TD Target 与网络预测值之间的误差来训练。

**记笔记版**

REINFORCE 是最基础的策略梯度算法，它通过采样完整轨迹，计算每一步之后的折扣累计回报 $﷐$$u$$﷮$$t$$﷯$，并用该回报更新策略参数。其思想是：如果某个动作之后获得较高回报，就提高该动作在相应状态下被选择的概率。但 REINFORCE 依赖完整轨迹回报，方差较大，训练不稳定。

Baseline 方法在策略梯度中引入基准值 $b$，将 $﷐$$Q$$﷮$$π$$﷯$$﷐$$s$$﷮$$a$$﷯$ 替换为 $﷐$$Q$$﷮$$π$$﷯$$﷐$$s$$﷮$$a$$﷯$$−$$b$，即优势值 Advantage。它表示某个动作相对于平均水平的好坏，可以降低梯度估计的方差，使训练更加稳定。

Actor-Critic 方法将策略学习和价值评估分开。Actor 是策略网络，负责根据状态选择动作；Critic 是价值网络，负责估计 $Q$$﷐$$s$$﷮$$a$$﷯$、$V$$﷐$$s$$﷯$ 或 Advantage，并用 TD 目标进行更新。Actor 根据 Critic 的评价调整动作概率，因此 Actor-Critic 比 REINFORCE 更高效、更稳定。

**6. PPO 最核心公式：Clipped Objective**

PPO 的核心目标是：

$﷐$$L$$﷮$$CLIP$$﷯$$﷐$$θ$$﷯$$=$$﷐$$E$$﷮$$t$$﷯$$﷐$$﷐$$min$$﷮$$﷐$$﷐$$r$$﷮$$t$$﷯$$﷮$$﷐$$θ$$﷯$$﷐$$A$$﷮$$t$$﷯$$clip$$﷐$$﷐$$r$$﷮$$t$$﷯$$﷮$$﷐$$θ$$﷯$$﷮$$1−$$ε$$1+$$ε$$﷯$$﷐$$A$$﷮$$t$$﷯$$﷯$$﷯$$﷯$

符号解释：

$﷐$$L$$﷮$$CLIP$$﷯$$﷐$$θ$$﷯$表示 PPO 的裁剪策略目标。

$﷐$$E$$﷮$$t$$﷯$表示对一批采样数据求平均。

$min$$﷐$$⋅$$﷮$$⋅$$﷯$表示取两个目标中较小的那个，也就是更保守的那个。

$﷐$$r$$﷮$$t$$﷯$$﷐$$θ$$﷯$$﷐$$A$$﷮$$t$$﷯$表示未裁剪的策略提升目标。

$clip$$﷐$$﷐$$r$$﷮$$t$$﷯$$﷮$$﷐$$θ$$﷯$$﷮$$1−$$ε$$1+$$ε$$﷯$$﷐$$A$$﷮$$t$$﷯$表示裁剪后的策略提升目标。

$﷐$$A$$﷮$$t$$﷯$表示优势函数。

人话理解：

PPO 会比较“正常更新目标”和“裁剪后的保守目标”，然后选择更保守的那个，防止策略更新太猛。

**记笔记版**

PPO 的训练过程首先使用旧策略 $﷐$$π$$﷮$$θ$$﷯$$﷐$$a$$∣$$s$$﷯$ 与环境交互，采样得到状态、动作、奖励、下一状态以及旧动作概率。然后利用 Critic 网络估计 $V$$﷐$$﷐$$s$$﷮$$t$$﷯$$﷯$ 和 $V$$﷐$$﷐$$s$$﷮$$t$$+1$$﷯$$﷯$，计算 TD Error：

$﷐$$δ$$﷮$$t$$﷯$$=$$﷐$$r$$﷮$$t$$﷯$$+$$γ$$V$$﷐$$﷐$$s$$﷮$$t$$+1$$﷯$$﷯$$−$$V$$﷐$$﷐$$s$$﷮$$t$$﷯$$﷯$

并进一步通过 GAE 计算优势函数：

$﷐$$A$$﷮$$t﷮$$GAE$$﷯$$=$$﷐$$δ$$﷮$$t$$﷯$$+$$γ$$λ$$﷐$$δ﷮$$t$$+1$$﷯$$+$$﷐$$﷐$$γ$$λ$$﷯$$﷮$$2$$﷯$$﷐$$δ﷮$$t$$+2$$﷯$$+⋯$

接着，新策略 $﷐$$π$$﷮$$﷐$$θ﷮$$′$$﷯$$﷯$ 在同样的状态和动作上重新计算动作概率，与旧策略概率形成比值：

$﷐$$r$$﷮$$t$$﷯$$﷐$$﷐$$θ$$﷮$$′$$﷯$$﷯$$=$$﷐$$﷐$$π$$﷮$$﷐$$θ$$﷮$$′$$﷯$$﷯$$﷐$$﷐$$a$$﷮$$t$$﷯$$∣$$﷐$$s$$﷮$$t$$﷯$$﷯$$﷮$$﷐$$π$$﷮$$θ$$﷯$$﷐$$﷐$$a$$﷮$$t$$﷯$$∣$$﷐$$s$$﷮$$t$$﷯$$﷯$$﷯$

最后 PPO 使用 clipped objective：

$﷐$$L$$﷮$$CLIP$$﷯$$=E$$﷐$$﷐$$min$$﷮$$﷐$$﷐$$r$$﷮$$t$$﷯$$﷮$$﷐$$A﷮$$t﷮$$GAE$$﷯$$c$$lip$$﷐$$﷐$$r$$﷮$$t$$﷯$$﷮$$1$$﷮$$−$$ε$$1+$$ε$$﷯$$﷐$$A$$﷮$$t$$﷮$$GAE$$﷯$$﷯$$﷯$$﷯$

来更新策略。PPO 的核心思想是：如果动作优势为正，就提高该动作概率；如果优势为负，就降低该动作概率；但通过 clip 限制新旧策略差距，防止更新过猛。

![[面试3--微调、LoRA、强化学习、RLHF-DPO-GRPO image 7.png]]

PPO 用 Critic 估计 Advantage；GRPO 不用 Critic，而是让同一个 prompt 生成多条回答，用组内奖励相对高低来算 Advantage。

**整张图一句话串起来**

这张图完整过程是：

从数据集中取一个 prompt，用旧模型生成多条 completions；对每条 completion 打 reward；在同一组内做 reward 归一化得到 advantage；然后分别计算 new、old、ref 三种 per-token logprob；用 new/old 概率比做 PPO-style clip 更新；再用 new/ref 的 KL 惩罚约束模型不要偏离参考模型太远。

**记笔记版**

GRPO 是一种面向大模型强化学习的策略优化方法。它与 PPO 类似，也使用概率比值和 clip 目标来限制策略更新幅度，但 GRPO 不依赖 Critic 估计优势函数，而是对同一个 prompt 采样多条回答，并根据组内 reward 的相对大小计算 advantage：

$﷐$$﷐$$A$$﷯$$﷮$$i$$﷯$$=$$﷐$$﷐$$r$$﷮$$i$$﷯$$−$$mean$$﷐$$﷐$$r$$﷮$$1$$﷯$$﷮$$...$$﷮$$﷐$$r$$﷮$$G$$﷯$$﷯$$﷮$$std$$﷐$$﷐$$r$$﷮$$1$$﷯$$﷮$$...$$﷮$$﷐$$r$$﷮$$G$$﷯$$﷯$$﷯$

然后对每条回答中的 token 计算新旧策略概率比：

$﷐$$r$$﷮$$i$$,$$t$$﷯$$﷐$$θ$$﷯$$=$$﷐$$﷐$$π$$﷮$$θ$$﷯$$﷐$$﷐$$o$$﷮$$i$$,$$t$$﷯$$﷮$$∣$$q$$﷐$$o$$﷮$$i$$,<$$t$$﷯$$﷯$$﷮$$﷐$$π$$﷮$$﷐$$θ$$﷮$$old$$﷯$$﷯$$﷐$$﷐$$o$$﷮$$i$$,$$t$$﷯$$﷮$$∣$$q$$﷐$$o$$﷮$$i$$,<$$t$$﷯$$﷯$$﷯$

并使用 PPO-style clipped objective：

$﷐$$min$$﷮$$﷐$$﷐$$r$$﷮$$i$$,$$t$$﷯$$﷮$$﷐$$θ$$﷯$$﷐$$﷐$$A$$﷯$$﷮$$i$$,$$t$$﷯$$clip$$﷐$$﷐$$r$$﷮$$i$$,$$t$$﷯$$﷮$$﷐$$θ$$﷯$$﷮$$1−$$ε$$1+$$ε$$﷯$$﷐$$﷐$$A$$﷯$$﷮$$i$$,$$t$$﷯$$﷯$$﷯$

来提高高优势回答的 token 概率、降低低优势回答的 token 概率。同时，GRPO 加入 KL 惩罚：

$−$$β$$﷐$$D﷮$$KL$$﷯$$﷐$$﷐$$π$$﷮$$θ$$﷯$$∥$$﷐$$π$$﷮$$ref$$﷯$$﷯$

防止当前模型偏离参考模型过远。GRPO 的核心优势是通过组内相对奖励替代 Critic，从而降低大模型 RL 训练成本

**上午：全参数微调和参数高效微调**

**LoRA 是什么？**

**LoRA = Low-Rank Adaptation，低秩适配。**

它是一种**参数高效微调方法**。意思是：

不直接更新大模型全部参数，而是在模型里插入少量可训练的小矩阵，只训练这些小矩阵。

**面试版回答可以这样说**

LoRA 是一种参数高效微调方法。它冻结原始大模型参数，只在部分线性层中加入可训练的低秩矩阵，通过学习低秩更新量来适配新任务。相比全量微调，LoRA 显著减少了训练参数量、显存占用和模型存储成本，并且可以方便地在不同任务之间切换适配器。

![[面试3--微调、LoRA、强化学习、RLHF-DPO-GRPO image 9.png]]

全参数微调会更新全部模型参数：

\[

W\rightarrow W'

\]

问题是：

- 显存占用大；
- 训练成本高；
- 每个任务都需要保存完整模型。

LoRA 冻结原参数，只训练低秩增量：

\[

\boxed{

W'=W+\Delta W

}

\]

其中：

\[

\Delta W=BA

\]

若：

\[

W\in\mathbb R^{d_{\text{out}}\times d_{\text{in}}}

\]

则：

\[

A\in\mathbb R^{r\times d_{\text{in}}},

\qquad

B\in\mathbb R^{d_{\text{out}}\times r}

\]

并且：

\[

r\ll

\min(d_{\text{in}},d_{\text{out}})

\]

需要训练的参数从：

\[

d_{\text{out}}d_{\text{in}}

\]

降低为：

\[

r(d_{\text{in}}+d_{\text{out}})

\]

这就是 LoRA 节约资源的原因。

重点理解：

- Rank (r)；
- Alpha；
- Target Modules；
- Adapter；
- LoRA 与 QLoRA；
- 训练后如何合并权重；
- 什么情况使用 LoRA。

**下午：强化学习基础**

五天准备不需要深入 DQN 和机器人控制，重点学习：

\[

\text{MDP}

\rightarrow

\text{策略梯度}

\rightarrow

\text{Actor-Critic}

\rightarrow

\text{PPO}

\]

MDP：

\[

\mathcal M=

(\mathcal S,\mathcal A,P,R,\gamma)

\]

累计回报：

**\[**

**G_t**

\sum_{k=0}^{\infty}

\gamma^k r_{t+k+1}

\]

价值函数：

**\[**

**V^\pi(s)**

\mathbb E_\pi\[G_t\mid S_t=s\]

\]

动作价值函数：

**\[**

**Q^\pi(s,a)**

\mathbb E_\pi\[G_t\mid S_t=s,A_t=a\]

\]

优势函数：

**\[**

**A^\pi(s,a)**

Q^\pi(s,a)-V^\pi(s)

\]

Actor-Critic：

- Actor：选择动作；
- Critic：评价动作。

**晚上：PPO、RLHF、DPO、GRPO**

**PPO**

新旧策略概率比：

**\[**

**r_t(\theta)**

\frac{

\pi_\theta(a_t\mid s_t)

}{

\pi_{\theta_{\text{old}}}(a_t\mid s_t)

}

\]

PPO 截断目标：

**\[**

**\boxed{**

**L^{\mathrm{CLIP}}**

\mathbb E_t

\left\[

\min

\left(

r_t\hat A_t,

\operatorname{clip}

(r_t,1-\epsilon,1+\epsilon)\hat A_t

\right)

\right\]

}

\]

核心理解：

PPO 允许策略改进，但限制一次更新不能过大。

**RLHF**

流程：

\[

\text{预训练}

\rightarrow

\text{SFT}

\rightarrow

\text{偏好数据}

\rightarrow

\text{奖励模型}

\rightarrow

\text{PPO}

\]

通常加入 KL 惩罚：

**\[**

**J(\theta)**

**\mathbb E\[r(x,y)\]**

\beta D_{\mathrm{KL}}

(\pi_\theta|\pi_{\mathrm{ref}})

\]

**DPO**

直接使用：

\[

(x,y_w,y_l)

\]

其中：

- (y_w)：偏好回答；
- (y_l)：不偏好的回答。

重点理解：DPO 不必单独训练奖励模型和执行完整 PPO 流程。

**GRPO**

同一个问题生成多个回答，基于组内相对奖励计算优势。面试中知道基本思想即可，不必五天内推导所有公式。
