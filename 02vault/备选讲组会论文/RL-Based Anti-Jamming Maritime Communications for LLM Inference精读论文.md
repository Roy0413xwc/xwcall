# RL-Based Anti-Jamming Maritime Communications for LLM Inference

> [!abstract] 一句话概括
> 面向海上恶劣信道与智能干扰下的多模态 LLM 推理任务，本文提出 LAMC，利用带历史反馈恢复和邻居观测聚合的 Actor-Critic 深度强化学习，联合选择数据压缩率、发射功率和传输信道；论文报告其在港口实测中相较 DAS 基线实现 **时延降低 40.5%、UE 能耗降低 46.4%、推理准确率提高 10.9%**。

## 2. 快速判断：这篇论文值不值得精读？

### 2.1 研究问题

- **应用场景：** 海上船舶、浮标或 UAV 等用户设备（UE）采集温度、湿度、气压、图像等==多模态数据==，上传到控制中心，由 LLaVA 等视觉语言模型完成环境理解和海上目标检测。
- **具体问题：** 在海面反射、波浪、天气、恶意智能干扰和多个 UE 竞争频谱的情况下，如何联合决定数据压缩率、发射功率和信道，兼顾通信可靠性、时延、UE 能耗与 LLM 推理准确率？
- **为什么重要：** 海上任务常需要及时识别船舶、人员和环境变化。即使模型本身准确，如果上传的数据因干扰而丢包或失真，最终推理结果仍可能不可靠；若一味提高发射功率，又会增加能耗且不一定能避开干扰。
- **现有方法的主要缺陷：**
  1. 传统抗干扰 RL 常根据 RSSI、CSI 或信道状态选择功率 / 信道，缺少环境语义、多模态数据大小和推理质量等信息。
  2. 海上信道反馈可能延迟或缺失，直接用不完整反馈更新策略会引入价值估计偏差。
  3. 仅优化通信指标，不一定能保证下游 LLM 推理准确率；只压缩数据也会在压缩开销、传输时延和推理质量之间产生权衡。
  4. 多 UE 同频传输会造成额外干扰，单 UE 的局部观测未必足以判断全局资源竞争状态。
- **作者的核心思路：** 将压缩率、发射功率和信道作为联合动作；将多模态数据大小、信道增益、能耗、时延、环境特征、干扰特征、接收包数和推理准确率纳入状态；聚合邻近 UE 的相关观测，并用历史抗干扰经验缓解反馈延迟 / 丢失；最后通过 Stackelberg 博弈推导性能上界。

### 2.2 30 秒总结

> 本文面向海上多模态通信与 LLM 推理场景，研究恶劣海上信道、智能干扰和多用户竞争下的联合传输策略优化。已有抗干扰方法通常没有充分利用环境语义、推理质量和延迟反馈信息。作者提出 LAMC，以 Actor-Critic 深度强化学习联合优化压缩率、发射功率和信道，并引入邻居观测聚合与历史反馈恢复。在港口实测中，相较 DAS 基线，论文报告时延降低 40.5%、UE 能耗降低 46.4%、推理准确率提高 10.9%。

## 3. 研究背景与文献脉络

### 3.1 背景与动机

- **研究背景：** 海上通信可服务于船舶交通监控、海上搜救和环境监测。摄像头提供丰富语义信息，但会受雾、雨、暗光影响；其他传感器可提供互补信息。多模态数据需要经无线链路上传到控制中心，再==由 LLM / 视觉语言模型理解场景。==
- **现实需求或理论动机：** 对海上任务而言，通信系统的目标不应仅是提高 SINR 或吞吐量，还应保证传到控制中心的数据足以支持及时、正确的推理。
- **关键难点：**
  1. 海面反射、蒸发波导、波浪和天气变化造成信道条件复杂。
  2. 恶意干扰器会根据传输状态和接收信号强度调整干扰策略。
  3. 多个 UE 竞争相同信道，形成同频干扰。
  4. 控制中心反馈的干扰状态、环境特征和推理指标可能延迟或丢失。
  5. 压缩率、发射功率、信道选择相互耦合，并影响时延、能耗与推理准确率。
- **为什么现有方法不够好：** 只根据 CSI / RSSI 优化链路，不能完整反映环境语义和任务质量；只追求通信可靠性，也可能导致过高的能耗；而只看单个 UE 的观测，则难以感知邻居的频谱竞争情况。

### 3.3 研究空白（Research Gap）

**作者声称的研究空白：**

1. 现有 RL 抗干扰方法缺少环境特征和多模态任务信息，难以直接保证 LLM 推理 QoS。
2. 恶劣海上信道可能造成反馈延迟或丢失，现有方法可能据此学习到次优策略并增加通信中断风险。
3. 需要在抗干扰通信场景中分析时延、UE 能耗和推理准确率之间的性能边界，并进行真实系统验证。

**我的判断：**

- 这些问题有实际意义，尤其是把“通信质量”扩展为“通信支撑下游推理任务的质量”。
- 单独使用 Actor-Critic、压缩、信道选择或 Stackelberg 博弈都不是全新的；创新更主要来自==**面向海上 LLM 推理的联合建模和系统集成**==。
- 论文的“研究空白”是否充分，还应与最接近的先前工作 [22] 对照。作者明确指出，本文相较其早期工作进一步利用 LLM 提取的环境特征和干扰特征，并增加反馈恢复机制、性能上界分析和硬件实现。
- 后续阅读时应重点核对：反馈恢复机制到底如何减少价值估计偏差；是否有消融实验能定量分离环境特征、邻居观测和历史反馈各自带来的增益。

## 5. 系统模型与问题建模
![[Pasted image 20261022171132.png]]

### 5.1 系统架构

- **网络组成：**
  - UE：船舶、无人机等，搭载相机、BME280 环境传感器和 Jetson Orin 计算平台。
  - 控制中心：接收压缩的多模态数据，运行 LLaVA 完成环境特征提取和海上目标检测；通过频谱感知获得干扰特征。
  - 智能干扰器：根据传输状态、接收信号强度和信道增益选择干扰策略。
  - 邻近 UE：在共享观测的机制下提供局部环境、数据和干扰信息，辅助当前 UE 决策。
- **节点数量与部署方式：** 仿真中通常考虑 5–25 个 UE；一组主要仿真使用 7 个 UE。港口实测使用 4 个 UE。仿真中的干扰器位置为 (18, 2, 0) m，控制中心位置为 (3, 18, 2) m。
- **上下行或通信链路：**
  1. 上行：UE 压缩多模态数据，选择发射功率和信道后发送至控制中心。
  2. 控制中心处理：LLM 提取环境特征、识别海上目标；系统计算接收包数、推理准确率、时延等指标。
  3. 干扰检测：USRP / 频谱感知模块估计被干扰信道与接收干扰功率。
  4. 下行反馈：环境特征、干扰特征、接收包数和推理性能等信息返回 UE。
  5. 策略更新：UE 根据当前状态、反馈和历史经验更新 Actor-Critic 网络。
- **主要信号流程：** ==多模态数据采集 → 压缩 → 选择功率与信道 → 抗干扰上行传输 → LLM 推理与频谱感知 → 性能评估 → 反馈 → 下一时隙策略选择。==
- **关键假设：**
  - 每个时隙可估计数据大小和 UE 到控制中心的信道增益。
  - 任务可表示为强化学习的状态—动作—效用序列。
  - 相邻 UE 能共享一定的观测信息，并可通过注意力权重减少冗余。
  - 性能上界分析使用简化的时延、能耗、准确率模型及特定博弈条件。
  - 实际链路和仿真链路的实现细节并不完全相同，分析时需区分。

### 5.2 信道与信号模型

- **信道类型：** 海上时变无线信道；论文使用三径路径损耗模型描述直达路径、海面反射和蒸发波导相关路径，并以对数距离路径损耗模型描述干扰器到控制中心的链路。它不是传统的纯 Rayleigh / Rician 小尺度衰落模型。
- **路径损耗与阴影衰落：** 论文式 (23) 建模海上路径损耗：

  \[
  L_p=20\log_{10}\left(
  \frac{\lambda\left|1+r_r\Delta_r e^{jkl_1}+r_d e^{jkl_2}\right|}
  {4\pi d}
  \right)
  \]

  其中，\(d\) 为距离，\(\lambda\) 为波长，\(k=2\pi/\lambda\) 为波数，\(r_r\) 和 \(r_d\) 分别表示粗糙海面与蒸发波导相关路径的反射系数，\(l_1,l_2\) 表示反射路径相对直达路径的路径差，\(\Delta_r\) 表示论文模型中的相关衰减 / 发散因素。公式按论文呈现转写，具体符号定义应以原文参考文献 [10] 为准。
- **小尺度衰落：** 文中提到信道衰落因素，但主要仿真建模重点是三径路径损耗和路径增益；不能据此认为论文完整建模了所有海上小尺度统计特性。
- **噪声与干扰：**
  - 噪声功率：\(\sigma\)。
  - 同频 UE 干扰：
    \[
    I=\sum_{j=1}^{Z}p_jh_j
    \tag{1}
    \]
    其中 \(p_j\) 为邻近 UE 的发射功率，\(h_j\) 为对应 UE 到控制中心的信道增益。
  - 智能干扰：干扰功率 \(y_1\)，干扰器到控制中心的信道增益 \(g\)。
- **信道状态信息（CSI）：** UE 使用导频估计到控制中心的信道增益 \(h\)。模型考虑状态反馈不及时的困难，但正文没有把完整 CSI 估计误差模型作为主要研究对象。
- **信道估计方式：** 通过 pilot signals 估计信道增益；干扰特征通过频谱感知获取。
- **移动性、多普勒或时延因素：** 仿真 UE 采用随机游走模型，速度为 5–10 m/s；路径损耗模型考虑海面反射、蒸发波导和地球曲率等影响。没有看到对多普勒频移和时延扩展进行深入建模的完整推导。
- **关键 SINR 公式：**

  \[
  \gamma=\frac{a_2h}{\sigma+I+y_1g}
  \tag{2e}
  \]

  其中 \(a_2\) 是当前 UE 的发射功率，\(h\) 是 UE 到控制中心的信道增益，\(I\) 是其他 UE 的同频干扰，\(y_1g\) 是干扰器造成的接收干扰功率。该式说明，提高发射功率或信道增益有利于 SINR，而噪声、邻居干扰和恶意干扰会降低 SINR。

| 符号 | 含义 | 维度 / 单位 | 是否可控 |
|---|---|---|---|
| \(h\) | UE 到控制中心的信道增益 | 线性增益 | 不直接可控，可估计 |
| \(g\) | 干扰器到控制中心的信道增益 | 线性增益 | UE 不直接可控 |
| \(\sigma\) | 噪声功率 | 功率单位 | 通常不可控 |
| \(I\) | 邻近 UE 的同频干扰 | 功率单位 | 受其他 UE 策略影响 |
| \(y_1\) | 干扰器发射功率 | W / mW | 干扰器可控 |
| \(a_1\) | 数据压缩率 | 无量纲，\((0,1]\) | UE 可控 |
| \(a_2\) | UE 发射功率 | W / mW | UE 可控 |
| \(a_3\) | 传输信道编号 | 离散编号 | UE 可控 |
| \(B\) | 信道带宽 | Hz | 本文主要作为系统参数 |
| \(\gamma_0\) | SINR 门限 | 线性值 | 设计参数 |

### 5.3 通信 / 感知 / 定位指标

**本文实际优化或评估的指标：**

- **SINR \(\gamma\)：** 衡量接收信号相对于噪声和干扰的质量；要求达到门限 \(\gamma_0\)。
- **推理准确率 \(\rho\)：** 控制中心对多模态数据进行 LLM 推理后的任务质量指标；文中描述其依据置信度等信息进行评估。
- **时延 \(\tau\)：** 包含传输时延 \(\tau_1\) 和推理时延 \(\tau_2\)。
- **UE 能耗 \(\xi\)：** 与发射功率、传输时延等因素有关。
- **接收包数 \(\iota\)：** 反映传输成功情况，并作为状态信息反馈。
- **效用 \(u\)：** 综合推理准确率、时延、能耗和 SINR 违约惩罚。
- **感知 / 检测输出：** 环境特征（如室内 / 室外、降雨指示）与海上目标类别（如船、码头、人员）；论文没有以 CRB、定位 RMSE 等作为核心指标。

### 5.4 优化问题 / 学习任务

**决策变量：**

\[
\mathbf a=[a_1,a_2,a_3]
\]

其中：

- \(a_1\)：数据压缩率；
- \(a_2\)：发射功率；
- \(a_3\)：信道选择。

论文给出的长期目标为最大化折扣累积效用：

\[
\max_{\mathbf a\in\mathcal A}
\mathbb E\left[
\sum_{n=k}^{\infty}
\vartheta^{n-k}
\left(\rho^{(n)}-\omega_0\tau^{(n)}-\omega_1\xi^{(n)}\right)
\right]
\tag{2a}
\]

约束为：

\[
a_1\in(0,1],\quad a_2\in[0,P],\quad
a_3\in\{1,2,\ldots,F\}
\tag{2b--2d}
\]

\[
\frac{a_2h}{\sigma+I+y_1g}\geq\gamma_0
\tag{2e}
\]

其中 \(\vartheta\) 为折扣因子，\(\omega_0\) 和 \(\omega_1\) 分别控制时延和能耗的重要程度，\(P\) 为 UE 最大传输功率，\(F\) 为信道数。

**即时效用函数：**

\[
u^{(k)}=\rho-\omega_0\tau-\omega_1\xi
-\Gamma\mathbb I(\gamma\leq\gamma_0)
\tag{5}
\]

\(\Gamma\) 是 SINR 未达门限时的惩罚系数，\(\mathbb I(\cdot)\) 为指示函数。

- **目标函数的物理意义：** 提高推理准确率，同时降低时延和 UE 能耗；对 SINR 未达门限的行为施加惩罚。
- **每个约束的物理意义：** 压缩率必须在允许区间；发射功率不能超过硬件上限；信道编号属于可用信道集合；SINR 需满足通信可靠性门限。
- **连续 / 离散变量：** 原始模型中压缩率、功率为连续变量，信道为离散变量；实际 DRL 实现将压缩率和功率量化为有限等级，因此动作空间可离散化。
- **问题是否非凸？原因是什么：** 目标和约束受到信道、干扰、压缩率、时延和推理准确率之间的耦合影响；动作中又包含离散信道选择，且环境状态未知或部分可观测，难以直接使用单一的传统优化算法求解。
- **论文采用的方法：** 用 MDP / DRL 进行交互式策略学习；用 Actor 网络生成动作策略，用 Critic 网络估计动作价值；通过经验回放与熵正则化更新网络；再通过 Stackelberg 博弈分析特定条件下的性能界。
- **模型假设是否过于理想化：** 性能上界使用简化的时延、能耗和准确率函数；实际 LLM 的准确率与压缩率、信道质量之间通常不一定严格满足简单解析关系。需要把理论界与真实系统结果分开理解。

## 6. 方法与算法

### 6.1 方法总览

**方法名称：** LAMC（RL-Based Anti-Jamming Maritime Communications for LLM Inference）。

**核心思想：**

1. 用多模态数据大小、信道增益、时延、能耗、环境特征、干扰特征、接收包数和推理准确率描述 UE 的局部观测。
2. 聚合邻近 UE 的相关观测，以扩展当前 UE 的信息范围，并降低重复信息的影响。
3. Actor 网络根据状态选择压缩率、发射功率和信道；Critic 网络估计状态—动作价值。
4. UE 将压缩数据上传给控制中心；控制中心运行 LLaVA，输出环境特征、目标检测结果和性能反馈。
5. 当反馈延迟或部分缺失时，使用过去时隙的历史抗干扰经验估计效用，降低错误价值估计的影响。
6. 将交互经验存入 replay buffer，随机采样小批量数据更新网络。
7. 使用 Stackelberg 博弈分析干扰器与多个 UE 的策略关系，并给出特定假设下的性能上界。

**输入：**

- 各模态数据大小 \(z\)；
- UE 到控制中心的信道增益 \(h\)；
- 时延 \(\tau\)、能耗 \(\xi\)；
- LLM 提取的环境特征 \(\alpha\)；
- 频谱感知得到的干扰特征 \(\mu\)；
- 接收包数 \(\iota\)、推理准确率 \(\rho\)；
- 邻近 UE 的共享观测。

**输出：** 压缩率 \(a_1\)、发射功率 \(a_2\)、传输信道 \(a_3\)。

**相比基线方法的关键变化：** 相较 DAS（基于双动作网络的 DRL 抗干扰算法），LAMC 不只使用链路状态，还把 LLM 环境特征、干扰信息、邻居观测和反馈恢复机制纳入策略学习，并直接把推理准确率作为效用组成部分。

### 6.2 算法流程

1. **初始化：** 初始化 Actor / Critic 网络参数、折扣因子、温度参数、学习率和经验回放缓存；将初始时延、能耗和推理准确率设为初值。
2. **获取状态：** 在第 \(k\) 个时隙估计各模态数据大小 \(z\) 和信道增益 \(h\)，读取本地时延、能耗及控制中心反馈的环境、干扰和推理指标。
3. **邻居观测聚合：** 根据本地与邻居观测的任务相似度计算注意力权重，形成去冗余的共享观测 \(\tilde o\)。
4. **构造状态：** 将本地观测和共享观测拼接为 \(s^{(k)}\)。
5. **策略选择：** Actor 根据状态输出动作概率分布，并选择 \(a^{(k)}=[a_1,a_2,a_3]\)。
6. **压缩与传输：** 按压缩率处理多模态数据，以选定功率在指定信道上传输。
7. **控制中心推理与干扰检测：** LLM 提取环境特征、识别船舶 / 人员等目标；频谱感知估计被干扰信道和接收干扰功率。
8. **性能评估：** 获取推理准确率、接收包数、时延和 UE 能耗，计算效用 \(u^{(k)}\)。
9. **反馈恢复：** 如果反馈延迟或缺失，则根据历史时隙的效用和校正项估计当前效用。
10. **经验回放与更新：** 将 \((s^{(k)},a^{(k)},u^{(k)},s^{(k+1)})\) 存入缓存；达到小批量大小后随机抽取经验，更新 Actor 与 Critic。
11. **循环执行：** 进入下一个时隙，持续学习以适应信道和干扰变化。

### 6.3 按方法类型补充

#### 如果是传统优化 / 信号处理

- **使用方法：** 频谱感知、导频信道增益估计、三径路径损耗建模、Stackelberg 博弈。
- **原始问题为什么难：** UE 与干扰器的动作相互影响，信道和干扰状态动态变化，多个 UE 之间存在频谱冲突；动作还包括离散信道选择。
- **关键变换与近似：** DRL 将长期策略优化转化为与环境交互的序列决策；性能分析采用简化的准确率、时延和能耗表达式。
- **每一步子问题是否可解：** 论文没有通过 AO / SCA / SDR 等方式逐块求解，而是以神经网络策略学习为主。
- **收敛性 / 最优性结论：** 文中通过仿真观察到性能随时隙收敛，并给出 Stackelberg 均衡下的性能界；这不等于证明一般非平稳、部分可观测环境中的 DRL 全局收敛。
- **计算复杂度：** 论文给出的 LAMC 复杂度为 \(O(DMLFK)\)，其中 \(D\) 是小批量大小，\(M\) 是压缩率等级数，\(L\) 是功率等级数，\(F\) 是信道数，\(K\) 是学习步数。
- **可能的局部最优或松弛误差：** 神经网络训练可能受初始化、超参数、奖励权重和训练分布影响；性能上界也依赖论文所列的条件。

#### 如果是深度学习 / 强化学习

- **学习范式：** [x] DRL；采用 Actor-Critic、经验回放和熵正则化。文中没有把整个方案称为某个明确的标准算法名称，不应仅凭熵项就直接断定其等同于完整 SAC 实现。
- **状态 / 输入：**

  \[
  o^{(k)}=[z,h,\xi,\tau,\alpha,\mu,\iota,\rho]
  \tag{3}
  \]

  聚合邻居观测后：

  \[
  s^{(k)}=[z,h,\xi,\tau,\alpha,\mu,\iota,\rho,\tilde o]
  \tag{4}
  \]

  其中 \(\tilde o\) 是去冗余的邻居观测。
- **动作 / 输出：**

  \[
  a^{(k)}=[a_1,a_2,a_3]
  \]

  实现中压缩率取有限等级 \(a_1\in\{m/M\}\)，发射功率取有限等级 \(a_2\in\{lP/L\}\)，信道 \(a_3\in\{1,\ldots,F\}\)。注意：原问题写功率范围为 \([0,P]\)，算法离散化公式采用从第 1 个等级开始的写法，零功率是否作为实际动作需按实现进一步核对。
- **奖励函数或损失函数：** 即时效用为
  \[
  u=\rho-\omega_0\tau-\omega_1\xi-\Gamma\mathbb I(\gamma\leq\gamma_0)
  \]
  Actor 更新中加入温度参数控制的熵项；Critic 通过最小化带折扣因子的 Bellman 目标误差进行更新。
- **网络结构：**
  - Actor：输入状态，经两个 ReLU 隐藏层，输出离散动作策略。
  - Critic：输入状态和动作相关表示，输出 Q 值。
  - 论文给出的一个配置为：状态输入维度 18，Actor 两个隐藏层各 128 个 ReLU 神经元；Critic 结构为 143、128、128、1 个节点。
  - **核查项：** 论文同时报告动作组合等级 \(M=5,L=5,F=10\)，其组合数 \(MLF=250\)，但正文又称 Actor 输出为 125 维。若输出维度代表全部联合动作类别，两者存在需要核对的口径差异。
- **训练数据如何产生：** 来自 UE 与动态海上通信环境的在线交互；每条经验包含当前状态、动作、效用和下一状态。仿真还使用 WaterScenes 的图像数据。
- **训练与部署是否存在分布差异：** 存在潜在差异。仿真使用随机游走、指定路径损耗和 Q-learning 干扰器；真实港口环境的传播、遮挡、硬件和干扰行为更复杂。论文未提供充分的跨海域迁移测试。
- **是否需要在线交互：** 训练阶段依赖交互与反馈；实际运行中需要持续获取通信和推理反馈。文中没有完整说明预训练策略能否在无在线探索的情况下直接部署。
- **泛化能力与推理开销：** Actor 推理开销通常较小，但状态采集、邻居观测交换、控制中心 LLM 推理和反馈链路仍产生系统开销。论文指出在特定设置下，6 个邻居的观测交换约为每时隙 162 字节，认为相较多模态数据传输可忽略。
- **与模型驱动方法如何结合：** 可将物理信道模型、SINR 门限、功率限制作为状态和约束；用博弈分析得到理论性能界；由 DRL 负责在未知动态环境中学习具体策略。

### 6.4 关键公式精读

| 公式编号 | 公式的作用 | 推导思路 | 使用的前提 | 是否理解 |
|---|---|---|---|---|
| 式 (1) | 汇总其他 UE 的同频干扰 | 对邻居发射功率与对应信道增益的乘积求和 | 干扰项可按接收功率加和建模 | 基本理解 |
| 式 (2a)–(2e) | 定义长期优化目标与 QoS 约束 | 折扣累积准确率减去时延、能耗代价，同时要求 SINR 达标 | 状态与反馈可用于估计效用；功率、信道和压缩率受限 | 基本理解 |
| 式 (3)–(4) | 构造局部观测与融合后的状态 | 本地状态拼接注意力聚合后的邻居观测 | 邻居能共享观测；相似度能反映任务相关性 | 需精读注意力权重 |
| 式 (5) | 定义单时隙效用 | 准确率作为正项，时延和能耗作为代价，SINR 违约额外惩罚 | 权重和惩罚系数经过设置 | 基本理解 |
| 式 (6) | 反馈延迟 / 缺失时估计效用 | 利用前 \(T\) 个时隙的历史效用及校正项降低估计偏差 | 历史经验对当前状态仍具有一定参考价值 | 需进一步核对实现细节 |
| 式 (7)–(8) | 更新 Actor / Critic | Actor 以策略梯度和熵正则项更新；Critic 最小化 Bellman 目标误差 | 经验回放样本可用于近似训练目标 | 基本理解，需结合 RL 基础复习 |
| 式 (9)–(12) | 构建 jammer 与 UE 的 Stackelberg 博弈 | 干扰器先选干扰功率，UE 再响应选择传输策略 | 领导者—跟随者顺序和效用函数成立 | 基本理解 |
| 式 (13)–(17) | 给出准确率模型和性能上界 | 将准确率写成压缩率与 SINR 的函数，进而推导时延、能耗、准确率界 | 满足文中指定条件与简化模型 | 需核对理论假设 |

**最关键的一条公式：**

\[
u^{(k)}=\rho-\omega_0\tau-\omega_1\xi
-\Gamma\mathbb I(\gamma\leq\gamma_0)
\tag{5}
\]

这条公式决定策略“偏好”什么：

- \(\rho\) 越高，效用越高；
- \(\tau\) 越大，时延代价越大；
- \(\xi\) 越大，能耗代价越大；
- 当 \(\gamma\leq\gamma_0\) 时，增加惩罚 \(\Gamma\)，鼓励策略满足最低链路质量要求。

它把通信层和应用层连接起来：不是只追求高 SINR，而是追求**可用的推理结果、较低的传输代价和满足 QoS 的链路质量**。

**性能上界中的关键关系：**

\[
\hat{\gamma}_i=\frac{P h_i}{\sigma+P_J g}
\tag{15}
\]

\[
\hat{\rho}_i=L\left(1-e^{-\hat{\gamma}_i}\right)
\tag{14c}
\]

\[
\hat{\tau}_i=
\frac{z_i}{B\log_2(1+\hat{\gamma}_i)}
+\frac{\Lambda}{\Omega}
\tag{14a}
\]

\[
\hat{\xi}_i=
\frac{Pz_i}{B\log_2(1+\hat{\gamma}_i)}
\tag{14b}
\]

其中 \(P\) 是最大 UE 发射功率，\(P_J\) 是最大干扰功率，\(h_i\) 和 \(g\) 分别为 UE / 干扰器到控制中心的信道增益，\(z_i\) 是数据大小，\(B\) 是带宽，\(\Lambda\) 是 LLM 推理所需的计算量，\(\Omega\) 是控制中心计算能力，\(L\) 是准确率模型的上限参数。

直观理解：

- \(\hat\gamma_i\) 增大时，\(\log_2(1+\hat\gamma_i)\) 增大，传输时延和按该模型计算的发射能耗下降。
- \(L(1-e^{-\hat\gamma_i})\) 随 SINR 增大而上升，但逐渐趋于饱和。
- 数据量 \(z_i\) 增大时，传输时延和能耗随之增加。
- 这些式子是理论分析中的简化性能模型，不代表真实 LLaVA 准确率在所有数据、压缩率和信道条件下都严格遵循这一函数。

- **港口实测（摘要 / 结论，比较 DAS）：**

## 8. 局限性与可改进方向

> [!question] 从审稿人和研究生的角度提出问题

### 8.1 论文局限

- **场景局限：** 港口实测只使用 4 个 UE，规模有限；仿真虽然覆盖 5–25 个 UE，但与真实船舶运动、遮挡和复杂海况仍有差异。
- **模型局限：** ==三径路径损耗比自由空间模型更贴近海上传播，但仍不能覆盖所有海况、船体遮挡、天线姿态、海面粗糙度变化和复杂多径。文中对多普勒、时延扩展等因素的建模不够突出。==
- **算法局限：** Actor-Critic 依赖奖励权重、训练经验和环境反馈；面对未见过的干扰策略或状态分布变化，是否仍能稳定工作尚未充分证明。
- **学习局限：** 邻居观测依赖信息交换；若共享信息也受到干扰、延迟或伪造，策略可能受影响。历史效用恢复也依赖历史经验对当前环境仍有参考价值。
- **实验局限：** DAS 是主要基线；逐模块消融与更广泛的干扰策略比较不足。仿真和实验中学习率参数存在不同数值口径，需要核实。
- **工程局限：** ==控制中心需要运行 LLM 推理、频谱感知和反馈服务；端到端时延不仅包括无线传输，还受到模型推理负载、GPU 资源和反馈链路影响。==
- **指标局限：** 论文将推理准确率纳入效用，但准确率与压缩率、SINR 的理论关系采用简化表达。真实视觉语言模型的错误类型、置信度校准和语义信息损失可能更复杂。
- **安全局限：** 主要考虑干扰器通过功率、频率和带宽干扰链路；尚未充分分析伪造反馈、对抗样本或针对 LLM 的语义攻击。

### 8.2 可以进一步研究的问题

| 改进方向                 | 当前不足                              | 可行方案                                                         | 预期收益                | 实现难度 |
| -------------------- | --------------------------------- | ------------------------------------------------------------ | ------------------- | ---- |
| 方向 1：面向未知干扰策略的鲁棒 DRL | 当前仿真与实测干扰模型有限，策略可能过拟合特定干扰器        | 在训练中随机化干扰功率、带宽、切换规律和观测误差；测试时加入未见过的干扰策略                       | 提高跨场景泛化和抗干扰鲁棒性      | 中    |
| 方向 2：不确定反馈下的状态估计     | 历史效用恢复依赖历史信息，未系统分析反馈延迟 / 丢包分布     | 引入 GRU / Transformer 时序状态编码、belief state 或带置信度的状态估计；显式模拟反馈丢失 | 更好地利用历史信息，降低状态估计偏差  | 中–高  |
| 方向 3：面向任务质量的自适应压缩    | 准确率模型较简化，压缩率与语义信息损失的关系可能非线性       | 用真实数据测量压缩率、SINR、模型输出质量之间的关系；将任务指标或感知损失纳入奖励                   | 更准确地平衡带宽、时延与推理质量    | 中    |
| 方向 4：通信与感知协同优化       | 当前以多模态数据上传和 LLM 推理为核心，未联合设计主动感知动作 | 将波束、感知周期、采样率、压缩率和传输资源联合优化；以目标检测 / 跟踪误差为任务指标                  | 向 ISAC、无人机感知与跟踪方向拓展 | 高    |

### 8.3 可形成的研究选题

**研究问题：**

面向低空无人机 / 海上无人平台，在干扰和反馈不可靠条件下，如何联合优化多模态感知数据压缩、通信资源分配与任务推理质量？

**与本文的区别：**

- 本文重点是海上多模态数据上传、LLM 推理和抗干扰策略。
- 可扩展方向可把感知任务指标（例如目标检测精度、跟踪误差或感知置信度）显式纳入优化，并考虑时变链路、任务优先级或多无人平台协同。
- 如果研究 ISAC，应明确加入通信与感知共享波形 / 资源的物理模型，不能仅仅把“LLM 推理”改名为“感知任务”就称为 ISAC。

**需要新增的模型 / 算法：**

- 时变无线信道与不确定 CSI；
- 反馈时延 / 丢包模型；
- 压缩率—任务质量的实测映射；
- 带任务约束的 DRL 奖励或约束式 RL；
- 可选：多智能体 RL、风险敏感 RL 或基于世界模型的短期状态预测。

**最小可行验证实验：**

1. 先搭建单 UE + 单干扰器仿真，验证联合压缩、功率和信道选择。
2. 加入不同反馈延迟 / 丢包率，对比“无恢复”“历史平均恢复”和“时序状态估计”。
3. 以 DAS、固定策略、随机策略和基础 Actor-Critic 为基线。
4. 评估平均时延、能耗、任务准确率、QoS 违约率与策略收敛速度。
5. 若要声称与 ISAC 有关，再引入明确的感知信号模型和感知性能指标。

**可能风险与备选方案：**

- 风险：同时优化太多变量会使问题难以复现、训练不稳定。
- 备选：先固定信道模型和数据压缩策略，只研究不可靠反馈下的鲁棒功率 / 信道选择；完成后再逐步增加任务质量和协同感知变量。

## 10. 组会汇报提纲

1. **背景与动机：** 海上通信受到海面反射、天气和智能干扰影响；传输质量会影响下游 LLM 环境理解和目标检测。
2. **现有工作不足：** 传统抗干扰方法主要优化功率 / 信道，缺少环境语义、任务质量和反馈缺失处理。
3. **系统模型：** UE 采集文本与图像，联合选择压缩率、功率和信道；控制中心运行 LLaVA 并反馈环境、干扰和性能信息。
4. **核心方法：** 状态中加入环境 / 干扰 / 邻居观测；Actor 选择动作，Critic 评估价值；历史经验辅助恢复延迟反馈。
5. **关键结果：** 重点讲图 7（拓扑变化下的性能）、图 8（不同 UE 数量下的平均性能）和图 11（港口实测）。
6. **创新与不足：** 创新主要在任务驱动的联合资源设计、反馈恢复和系统验证；不足在于消融、跨环境泛化与反馈模型的验证仍可加强。
7. **讨论问题：** 当前性能增益有多少来自新增状态特征，有多少来自历史反馈恢复？论文还需要怎样的消融实验才能把两者区分开？

**用 1 分钟讲清这篇论文：**

这篇论文研究海上多模态数据在智能干扰和恶劣信道下如何可靠上传，以支撑控制中心的 LLM 环境理解和目标检测。作者提出 LAMC，利用深度强化学习联合优化压缩率、发射功率和信道选择，并把环境特征、干扰特征、邻居观测以及历史反馈恢复纳入决策闭环。论文还用 Stackelberg 博弈推导时延、能耗和准确率的性能界，并通过仿真和港口硬件实验验证方法。港口实测相较 DAS 报告时延降低 40.5%、能耗降低 46.4%、推理准确率提高 10.9%。其价值主要在于把通信资源分配与下游推理任务质量结合起来；下一步应通过消融实验和更复杂干扰测试，进一步验证各模块的独立贡献与泛化能力。

**组会上最值得讨论的问题：**

## 11. 最终总结与个人收获

### 11.1 三句话总结

- **问题：** 海上多模态数据上传面临智能干扰、复杂传播、同频竞争和反馈不可靠等问题，传统只优化链路指标的方法难以保证 LLM 推理任务质量。
- **方法：** LAMC 用 Actor-Critic DRL 联合选择压缩率、发射功率和信道，并结合环境 / 干扰特征、邻居观测聚合和历史反馈恢复。
- **结论：** 在论文给出的仿真和港口实验条件下，LAMC 相较 DAS 改善了时延、UE 能耗和推理准确率；但跨环境泛化、模块消融和理论模型与真实推理质量之间的关系仍值得进一步验证。

### 11.2 我真正学会了什么？

- **新概念：** 任务驱动通信、部分可观测状态、反馈延迟恢复、Stackelberg 抗干扰博弈。
- **新模型 / 公式：** 将 SINR、推理准确率、时延和能耗共同纳入效用；用海上三径路径损耗表示海面反射和蒸发波导影响。
- **新算法：** Actor-Critic 联合资源决策、经验回放、熵正则化和注意力式邻居观测聚合。
- **新的实验分析方法：** 同时观察时延、能耗、推理准确率和效用；区分仿真平均值、特定时隙结果与真实硬件测试结果。

3. **鲁棒性研究：** 进一步考虑延迟 CSI、反馈丢包、未知干扰策略或用户域偏移，比较历史平均、时序网络和模型预测等方法。
