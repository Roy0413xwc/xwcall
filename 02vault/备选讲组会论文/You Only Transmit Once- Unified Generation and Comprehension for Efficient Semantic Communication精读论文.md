# You Only Transmit Once: Unified Generation and Comprehension for Efficient Semantic Communication

> \[!abstract\] 一句话概括 本文提出 YOTO（You Only Transmit
> Once）生成式语义通信框架：发送端只传输压缩后的视觉语义特征，通过联合源信道压缩（SFS、CFS
> 与
> Libra）降低传输开销，接收端则可切换图像解码器或多模态语言模型，在同一传输表示上完成图像重建与图像描述生成。

### 2.1 研究问题

-   **应用场景：**
    带宽受限、信道存在噪声或衰落时，发送图像，接收端既可能需要恢复图像，也可能只需要理解图像并生成文字描述。
-   **具体问题：**
    如何只传输一份视觉语义表示，同时支持图像重建与图像描述生成，并在高压缩率下尽量保留对下游任务有用的信息？
-   **为什么重要：**
    传统通信强调尽可能准确地恢复全部数据；语义通信则希望优先传输与任务有关的信息。图像重建与图像理解对信息的需求不同，因此需要在视觉细节、语义信息和信道鲁棒性之间进行权衡。
-   **现有方法的主要缺陷：**
    1.  多模态系统可能需要传输多种模态的特征或索引，增加带宽开销。
    2.  将图像先转换为文本再传输，可能造成不可逆的视觉细节损失。
    3.  源端冗余压缩与信道端抗噪压缩常被分别考虑，难以协同分配有限的传输预算。
    4.  许多系统缺少可控的文本生成能力，难以按用户偏好生成不同情感风格的描述。
-   **作者的核心思路：** 发送端只编码并传输视觉表示；用 SFS
    去除源特征冗余、CFS 去除调制窗口中的冗余，并用 Libra
    根据源特征保留率与信道状态调节二者的压缩比例。接收端切换图像解码器或语言模型，即可完成不同任务。

### 2.2 30 秒总结

> 本文面向带宽受限且存在信道噪声/衰落的图像语义通信场景，研究如何用一次视觉特征传输同时支持图像生成（重建）与语义理解（图像描述）。已有方法可能需要额外传输多模态信息，或在模态转换中丢失信息，也缺少源端和信道端压缩的联合调节。作者提出
> YOTO，以 VQ 视觉表示、端到端数字调制自编码器、SFS/CFS/Libra
> 联合压缩，以及基于视觉因果模块和桥接模块的 GPT-2
> 文本解码器实现统一框架。论文报告在 SNR = 6 dB 时，AWGN 与 Rayleigh
> 信道下的图像重建 PSNR 均超过 30 dB；在 SNR = 10 dB 时，句子相似度超过
> 0.83。

## 3. 研究背景与文献脉络

### 3.1 背景与动机

-   **研究背景：**
    传统通信通常先对源数据压缩，再进行信道编码和调制，目标偏向可靠恢复数据；语义通信更关注接收端能否完成任务。
-   **现实需求或理论动机：**
    在无线带宽与信道质量有限时，不一定需要恢复图像中的每个像素；如果任务是图像描述，保留关键对象、属性和关系可能更重要。
-   **关键难点：**
    1.  图像重建需要纹理、边缘等低层视觉信息，图像理解需要全局语义和对象关系，两类任务的偏好并不相同。
    2.  源特征压缩与抗信道噪声的特征压缩相互影响。
    3.  信道扰动可能使视觉 token 出错，进而引发文本生成错误或对象幻觉。
    4.  如何在不增加第二路文本传输的情况下，使视觉表示同时服务于图像和文本解码。
-   **为什么现有方法不够好：**
    单纯提高图像重建质量，不一定能提高描述准确率；单纯生成语义文本，也可能丢失纹理、空间结构等视觉信息。

3.

## 5. 系统模型与问题建模

### 5.1 系统架构

-   **网络组成：**
    发送端视觉编码器、数字调制自编码器、无线信道；接收端数字解调器，以及二选一的视觉解码器或多模态语言模型（MLM）。
-   **输入：** 原始图像 (s_I
    `\in `{=tex}`\mathbb{R}`{=tex}\^{h`\times `{=tex}w`\times `{=tex}c})，以及由
    CLIPSeg 生成的 ROI mask (s_m
    `\in `{=tex}`\mathbb{R}`{=tex}\^{h`\times `{=tex}w})。
-   **主要信号流程：**
    1.  图像切分为 patch，经 RSSB 提取细粒度、中粒度、粗粒度特征。
    2.  ROI mask 与视觉特征融合；特征经 VQ 量化为离散 codebook 索引。
    3.  SFS 删除源端冗余特征；索引经滑动窗口处理后输入数字调制 AE。
    4.  CFS 结合信道噪声估计筛除窗口冗余；Libra 调整 SFS 与 CFS
        的保留率。
    5.  发送归一化后的实值信号，通过无线信道。
    6.  接收端均衡、解调后，选择视觉解码器重建图像，或选择 MLM
        生成图像描述。
-   **关键假设：** 主实验考虑 AWGN 与 Rayleigh
    fading；补充实验采用准静态 TDL-A 信道，并用 LS 估计
    CSI。发送端和接收端共享 VQ codebook；推理时需要图像与 ROI mask。

### 5.2 信道与信号模型

-   **信道类型：** \[x\] AWGN \[x\] Rayleigh fading \[x\] 准静态

-   **路径损耗与阴影衰落：** 主模型未建立显式路径损耗/阴影衰落模型。
-   **小尺度衰落：** Rayleigh fading；补充实验使用 3GPP TDL-A

-   **噪声与干扰：** AWGN；文中没有建立多用户同频干扰模型。
-   **CSI：** 主实验信道建模较理想；补充实验比较完美 CSI 与 LS 不完美

-   **信道估计方式：** 补充实验采用最小二乘（LS）估计

论文给出的 CBR 定义为：

\[ `\mathrm{CBR}`{=tex}=`\frac{2L_s}{cwh}`{=tex}. \]

在 CFS 滑动窗口的表达下，论文还写为：

\[ `\mathrm{CBR}`{=tex}=`\frac{2L_vL_w r_{\mathrm{CFS}}}{cwh}`{=tex}. \]

其中 (L_v) 为量化后的视觉特征总数，(L_w) 为窗口长度。CBR
越低，表示相对于原始图像所使用的传输符号越少，但通常也意味着更强的信息压缩与更高的重建风险。

### 5.3 通信 / 感知 / 定位指标

本文不是 ISAC、定位或波束成形论文，核心是语义通信。实际评估指标如下：

  -------------------------------------------------------------------------------------------
  任务                    指标                               含义
  ----------------------- ---------------------------------- --------------------------------
  图像重建                PSNR                               衡量像素重建误差，越高通常越好

  图像重建                SSIM                               衡量结构相似性，越高越好

  目标检测                mAP50                              IoU 阈值为 0.5 时的平均检测精度

  图像描述                ROUGE-L                            基于最长公共子序列评估文本重叠

  图像描述                Sentence Similarity                用预训练 BERT
                                                             得到文本嵌入，再计算余弦相似度

  图像描述                SPICE                              比较描述中的对象、动作及关系

  幻觉评估                CHAIRs / CHAIRi                    句子级 /
                                                             对象实例级幻觉率，越低越好

  情感可控生成            VADER compound score               评估生成描述的情感倾向

  计算开销                参数量、GFLOPs、吞吐量、推理时延   评估复杂度与部署潜力

句子相似度的定义：

\[ `\operatorname{similarity}`{=tex}(s_T,`\hat `{=tex}s_T)=

其中 (B(`\cdot`{=tex})) 为预训练 BERT 的文本语义表示。

### 5.4 优化问题 / 学习任务

**决策变量：** - 视觉编码器、数字调制 AE、视觉解码器参数； - SFS
的源特征保留率； - CFS 的二值掩码与信道特征保留率； - Libra
的调节网络参数； - 文本侧视觉因果模块、桥接模块、LoRA 与 prompt 参数。

**目标函数：**
论文没有把系统写成传统的单一约束优化问题，而是通过端到端损失训练不同阶段的网络。

图像传输阶段：

\[ `\mathcal `{=tex}L\_{`\mathrm{img}`{=tex}}
=`\mathcal `{=tex}L\_{`\mathrm{VQ}`{=tex}}
+`\lambda`{=tex}*g`\mathcal `{=tex}L*{`\mathrm{GAN}`{=tex}}
+`\lambda`{=tex}*{lb}`\mathcal `{=tex}L*{lb}. \]

其中： -
(`\mathcal `{=tex}L\_{`\mathrm{VQ}`{=tex}})：图像重建失真与连续/量化特征之间的码本学习损失；重建失真结合
MSE 与 LPIPS。 -
(`\mathcal `{=tex}L\_{`\mathrm{GAN}`{=tex}})：原始图像判别器与 patch
判别器的对抗损失，用于改善感知质量。 - (`\mathcal `{=tex}L\_{lb})：使
Libra 输出的目标保留率与 CFS 实际掩码保留率相匹配。 -
(`\lambda`{=tex}*g,`\lambda`{=tex}*{lb})：不同损失项的权重。

文本理解阶段：

\[
`\mathcal `{=tex}L\_{`\mathrm{text}`{=tex}}=`\mathcal `{=tex}L\_{`\mathrm{ar}`{=tex}}+`\mathcal `{=tex}L\_{`\mathrm{cl}`{=tex}},
\]

其中 (`\mathcal `{=tex}L\_{`\mathrm{ar}`{=tex}})
是自回归文本生成交叉熵损失，(`\mathcal `{=tex}L\_{`\mathrm{cl}`{=tex}})
是视觉语义 token 与文本语义表示的对比学习损失。

-   **物理意义：**
    在图像失真、视觉感知质量、特征压缩与文本语义正确性之间进行权衡。
-   **约束条件：** 发射功率归一化；SFS/CFS 的保留率位于 (\[0,1\])；CFS
    窗口中心特征强制保留。
-   **连续 / 离散变量：** 网络权重、特征向量是连续变量；VQ
    索引和特征掩码是离散变量。
-   **是否非凸：** 深度网络、VQ、GAN
    与离散掩码共同使训练目标非凸；论文未提供全局最优性证明。
-   **松弛 / 近似：** CFS 使用 Gumbel-Softmax
    处理离散掩码学习；端到端训练近似联合优化。
-   **模型假设是否理想化：**
    主实验信道相对简化；未覆盖多用户干扰、视频时序、复杂移动性和完整工程链路。

## 6. 方法与算法

### 6.1 方法总览

**方法名称：** YOTO（You Only Transmit Once）。

**核心思想：**
用一次视觉语义传输支持不同的接收端任务；通过源端和信道端联合筛选冗余特征，在控制
CBR 的同时尽量保留重建和理解所需的信息。

**输入：** 图像与 ROI mask；训练文本阶段还需要对应的图像描述和情感标签 /
prompt。

**输出：** 图像重建结果，或描述图像内容的文本；文本可以通过 prompt
控制为中性、正向或负向风格。

**相比基线方法的关键变化：** 1. 使用 VQ 离散视觉 token，并通过数字调制
AE 学习适合信道的传输表示。 2. SFS、CFS、Libra
联合处理源冗余与信道冗余。 3.
接收端替换解码网络即可切换图像重建与图像描述任务。 4.
文本解码端使用预训练 GPT-2，并通过 LoRA 和 prompt
降低训练成本、控制生成风格。

### 6.2 算法流程

**阶段一：图像到图像（生成 / 重建）**

1.  **输入准备：** 输入图像和 ROI mask；CLIPSeg mask
    可离线预计算、缓存，以减少在线延迟。
2.  **多粒度编码：** RSSB 提取细粒度、中粒度、粗粒度视觉特征，融合 ROI
    先验。
3.  **向量量化：** 将连续视觉特征映射到 VQ codebook，获得离散索引。
4.  **SFS 源特征选择：** 根据局部空间统计生成二值掩码，过滤部分源特征。
5.  **数字调制 AE：**
    对离散索引做滑动窗口处理，经端到端调制编码器得到适合信道传输的特征。
6.  **CFS 信道特征选择：** 将噪声方差估计输入
    MLP，并与调制特征融合；评估窗口内外围特征与中心目标特征的相关性，生成掩码。
7.  **Libra 联动调节：** 根据 (r\_{`\mathrm{SFS}`{=tex}}) 和噪声估计调节
    CFS 的保留率，协调压缩率与重建质量。
8.  **信道传输：** 功率归一化后经 AWGN 或 Rayleigh 信道发送。
9.  **接收端解码：** 均衡、数字解调、恢复视觉
    token；使用分层条件概率解码器逐级恢复粗、中、细粒度特征并重建图像。
10. **训练目标：** 最小化 VQ-VAE / 感知失真、GAN 与 Libra 相关损失。

**阶段二：图像到文本（理解 / 描述）**

1.  冻结视觉编码器和数字调制 AE，沿用同一发送端及接收视觉 token。
2.  视觉因果干预适配器通过可学习 query
    与对象混淆字典交互，降低数据集先验偏差。
3.  桥接模块使用 Slot Attention 聚合对象相关信息，再经因果
    self-attention 与映射网络转换到语言模型嵌入维度。
4.  将视觉语义 token 与文本 token 表示融合，作为 GPT-2 的上下文前缀。
5.  使用 LoRA 对 GPT-2 的注意力 QKV 投影和前馈网络进行参数高效微调。
6.  使用 hard / soft / hybrid prompts
    控制生成风格；推理时自回归生成文本，直到达到长度限制或输出 EOS。
7.  训练时联合自回归交叉熵损失与图文对比学习损失。

### 6.3 按方法类型补充：深度学习

-   **学习范式：** 监督学习 + 端到端联合训练 + 对比学习；不是强化学习。
-   **状态 / 输入：** 图像 patch、ROI mask、量化视觉
    token、噪声方差估计、图像对应文本。
-   **动作 / 输出：** SFS/CFS 特征掩码、调制特征、重建图像或生成描述。
-   **奖励函数或损失函数：** 图像阶段
    (`\mathcal `{=tex}L\_{`\mathrm{img}`{=tex}})；文本阶段
    (`\mathcal `{=tex}L\_{`\mathrm{text}`{=tex}})。
-   **网络结构：**
    -   RSSB：基于 2D Selective Scan / State Space Model
        的视觉模块，结合局部特征增强与通道注意力。
    -   SFT + GDN：融合 ROI 先验并归一化视觉特征。
    -   VQ：将连续特征量化为离散 codebook 索引。
    -   数字调制 AE：联合学习调制与解调，适应下游语义任务。
    -   SFS：利用局部空间信息统计筛选源端特征。
    -   CFS：根据窗口特征相关性与信道噪声估计筛选信道侧冗余。
    -   Libra：协调源特征与信道特征的保留率。
    -   文本解码器：视觉因果干预适配器 + Slot Attention + 映射网络 +
        GPT-2/LoRA。
-   **训练数据：** 图像生成任务使用 MS COCO 2014/2017；理解任务使用
    SentiCap，并扩充部分 MS COCO 样本，最终构建约 10,000
    对图像---文本训练样本。
-   **训练与部署分布差异：** 训练时使用 SNR = -4、2、8 dB；测试覆盖 -6
    至 18 dB。跨数据集、跨场景泛化没有充分展开。
-   **是否需要在线交互：**
    不需要强化学习式在线交互；推理阶段需要执行神经网络前向传播。
-   **泛化能力与推理开销：**
    视觉生成侧参数量和吞吐量较有竞争力；文本生成侧因自回归语言模型而更慢。
-   **与模型驱动方法结合：** 信道方程、功率归一化、CSI 估计与 ZF
    均衡提供物理层基础，神经网络学习特征压缩与调制解调。

### 6.4 关键公式精读

#### 公式一：信道输入输出关系


$1+1=2$

\[
$`\mathbf `{=tex}y^v=`\mathbf `{=tex}h`\mathbf `{=tex}x^v+`\mathbf `{=tex}n.$
\]

-   **作用：** 描述发射信号经过无线信道后受到衰落和噪声影响的过程。
-   **推导思路：** 将复数基带模型的实部与虚部展开成二维实值等效形式。
-   **使用前提：**
    单个数据块内采用给定的信道系数；更复杂的时变信道需进一步建模。
-   **是否理解：** 待结合 ZF 均衡和不完美 CSI 实验进一步学习。

#### 公式二：VQ 量化

\[ `\mathbf `{=tex}z\^{vq}*{j,i}
=`\operatorname{quant}`{=tex}(`\hat{\mathbf z}`{=tex}*{j,i})
=`\arg`{=tex}`\min`{=tex}*{`\mathbf `{=tex}c_k`\in`{=tex}`\mathcal `{=tex}C}
\|`\hat{\mathbf z}`{=tex}*{j,i}-`\mathbf `{=tex}c_k\|*2, `\qquad`{=tex}
`\operatorname{Ind}`{=tex}*{j,i}=k. \]

-   **作用：** 把连续视觉特征映射到最近的 codebook
    向量，以离散索引表示视觉内容。
-   **关键点：**
    传输的是索引相关信息，而不是直接传输全部连续视觉特征；量化有利于压缩，但可能引入量化失真。

#### 公式三：源特征保留率

\[ r\_{`\mathrm{SFS}`{=tex}}=
`\frac{L_{cg}r_1+L_{mg}r_2+L_{fg}r_3}`{=tex} {L\_{cg}+L\_{mg}+L\_{fg}}.
\]

-   (L\_{fg},L\_{mg},L\_{cg})：细、中、粗粒度 token 数量。
-   (r_1,r_2,r_3)：三个粒度的特征保留比例。
-   **作用：** 把多粒度各自的保留率汇总为总体源特征保留率。

#### 公式四：空间信息熵（SFS）

论文先对局部特征 patch 的像素值进行分箱，计算像素值与 bin 的高斯距离：

\[
f\_{p,e}=`\exp`{=tex}`\left`{=tex}(-`\frac{(p-e)^2}{2\sigma^2}`{=tex}`\right`{=tex}),
\]

再进行归一化，并计算局部特征图的空间信息熵：

\[ H(`\Omega`{=tex})=-`\sum`{=tex}*e
`\bar `{=tex}f*{`\Omega`{=tex},e}`\log `{=tex}`\bar `{=tex}f\_{`\Omega`{=tex},e}.
\]

-   **作者的解释：** 高熵 patch
    通常代表更复杂、语义信息更丰富的区域；低熵 patch
    可能更平坦、冗余更多。
-   **复核提示：**
    正文后续出现"保留最低熵元素"的文字，与前面对高/低熵的解释可能不一致。复现时应核对掩码生成逻辑。

#### 公式五：CBR

\[ `\mathrm{CBR}`{=tex}=`\frac{2L_s}{cwh}`{=tex}. \]

-   **作用：** 量化传输信号数量相对原始图像数据规模的比例。
-   **直观理解：** 降低 CBR
    意味着减少传输符号，但通常会增加信息损失风险。

#### 公式六：图像传输损失

\[ `\mathcal `{=tex}L\_{`\mathrm{img}`{=tex}}
=`\mathcal `{=tex}L\_{`\mathrm{VQ}`{=tex}}
+`\lambda`{=tex}*g`\mathcal `{=tex}L*{`\mathrm{GAN}`{=tex}}
+`\lambda`{=tex}*{lb}`\mathcal `{=tex}L*{lb}. \]

-   (`\mathcal `{=tex}L\_{`\mathrm{VQ}`{=tex}})：重建失真、感知损失与量化表示学习。
-   (`\mathcal `{=tex}L\_{`\mathrm{GAN}`{=tex}})：提高生成图像的感知质量。
-   (`\mathcal `{=tex}L\_{lb})：协调 Libra 输出和 CFS 实际保留率。
-   **需要注意：**
    各项损失的具体权重会影响像素质量、视觉真实性与压缩率的平衡。

#### 公式七：文本生成损失

\[ `\mathcal `{=tex}L\_{`\mathrm{text}`{=tex}}
=`\mathcal `{=tex}L\_{`\mathrm{ar}`{=tex}}+`\mathcal `{=tex}L\_{`\mathrm{cl}`{=tex}}.
\]

-   (`\mathcal `{=tex}L\_{`\mathrm{ar}`{=tex}})：让模型预测正确的后续文本
    token。
-   (`\mathcal `{=tex}L\_{`\mathrm{cl}`{=tex}})：让匹配的图像语义与文本表示在嵌入空间更接近。
-   **作用：** 同时优化文本生成能力与图文语义对齐。

**最关键的一条公式：** (`\mathcal `{=tex}L\_{`\mathrm{img}`{=tex}}) 与
(`\mathcal `{=tex}L\_{`\mathrm{text}`{=tex}})
代表两阶段的不同目标；它们共享发送端表示，但并非用一个统一损失直接端到端联合训练所有模块。

**我还不理解的数学 / 通信概念：** - \[\[联合源信道编码（JSCC）\]\] -
\[\[向量量化（VQ）\]\] - \[\[空间信息熵\]\] - \[\[Gumbel-Softmax\]\] -
\[\[状态空间模型（SSM）与 Mamba\]\] - \[\[LoRA\]\] - \[\[对比学习\]\] -
\[\[CSI 估计与零迫均衡（ZF）\]\]

## 8. 局限性与可改进方向

### 8.1 论文局限

-   **场景局限：**
    主要处理单张图像与图像描述，不包含视频时序；未建模多用户竞争和同频干扰。
-   **模型局限：** 主实验使用 AWGN 与 Rayleigh；TDL-A
    作为补充，但仍采用准静态数据块假设。没有显式讨论高速移动、多普勒与端到端时延扩散的完整影响。
-   **算法局限：** VQ 与二值掩码会引入不可逆信息损失；SFS
    的熵筛选文字描述存在需核实的潜在不一致；Libra 没有全局最优性证明。
-   **学习局限：** 文本任务训练数据约 10,000 对，规模相对有限；对预训练
    GPT-2 的依赖可能影响跨域泛化。
-   **实验局限：** 缺少明确的多随机种子统计；高 SNR
    下传统分离式方法可能更优；对不同压缩率、功耗和时延的联合权衡还可更系统。
-   **工程局限：** 文本自回归解码吞吐量较低；ROI mask
    的生成若在线执行会增加时延，因此论文采用预计算与缓存策略。

### 8.3 可形成的研究选题

**研究问题：** 面向不完美 CSI 的鲁棒、可变压缩率生成式语义通信。

**与本文的区别：** 不只是增加一个网络模块，而是把 CSI
不确定性、目标语义质量和 CBR
约束明确纳入统一设计，系统研究不同信道估计误差下的压缩策略。

**需要新增的模型 / 算法：** 1. CSI 误差模型，例如
(`\hat `{=tex}h=h+e)，其中 (e) 表示估计误差。 2.
可变压缩率控制模块，输入 SNR/CSI 置信度、任务类型和目标时延。 3.
鲁棒训练或风险敏感损失，使平均性能与最差信道下的表现都得到控制。

**最小可行验证实验：** - 复现 AWGN / Rayleigh 的图像传输基线。 -
逐步增加 CSI 估计误差，比较完美 CSI、LS CSI 与鲁棒训练版本。 - 横轴使用
SNR 或 CSI 误差方差，纵轴同时画 PSNR、句子相似度和 CBR。 - 比较固定 CBR
与自适应 CBR，并报告推理时间。

**可能风险与备选方案：** 若完整 YOTO 代码不可得，可先用公开 JSCC
模型验证"CSI 不确定性 +
自适应特征保留率"这一独立问题，再逐步加入文本任务。

3.  **系统模型：** 图像 + ROI mask → 多粒度视觉编码 / VQ → SFS →
    数字调制 AE / CFS / Libra → 无线信道 → 图像解码器或 GPT-2。
4.  **核心方法：** 用 Fig. 4 重点讲清 SFS、CFS 与 Libra 的分工；用 Fig.
    5 解释视觉 token 如何映射到语言模型。

    的有损语义压缩是否仍有优势？怎样设计自适应机制，在传统无损传输与语义压缩之间切换？

**用 1 分钟讲清这篇论文：**

> 这篇论文提出
> YOTO，一种统一图像重建和图像理解的生成式语义通信系统。发送端将图像编码成离散视觉
> token，通过 SFS 删除源特征冗余、CFS 删除信道侧冗余，并由 Libra
> 联动两种保留率。经过无线信道后，接收端可以选择视觉解码器恢复图像，也可以把解调后的视觉

> 在中低 SNR 下具有较强鲁棒性；不过在高 SNR
> 下，传统分离式编码可能恢复得更准确，而且文本解码开销较高。

## 11. 最终总结与个人收获

### 11.1 三句话总结

-   **问题：**
    在受限无线带宽和噪声信道下，如何用一次视觉特征传输同时支持图像重建与图像理解？
-   **方法：** 通过 VQ、多粒度 RSSB、数字调制 AE、SFS/CFS/Libra
    联合压缩，以及视觉因果---桥接---GPT-2 文本解码器完成统一设计。
-   **结论：** YOTO 在中低 SNR
    和高压缩条件下表现出较强的图像与文本任务性能，但高
    SNR、文本推理开销和复杂场景泛化仍是限制。

### 11.2 我真正学会了什么？

-   **新概念：** 任务导向语义通信、VQ 视觉 token、CBR、SFS/CFS、Libra。
-   **新模型 / 公式：**
    实值等效信道模型、CBR、源特征保留率、图像阶段与文本阶段损失。
-   **新算法：** 用 Gumbel-Softmax
    学习离散掩码；用对比学习改善图文语义对齐；用 LoRA 微调语言模型。
-   **新的实验分析方法：** 不只看 PSNR，也用 mAP50、SPICE、句子相似度与
    CHAIR 评估任务语义和幻觉。
